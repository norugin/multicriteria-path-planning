# Статистическая обработка

## Описательные показатели

Для каждого варианта вычисляются средние значения и выборочные стандартные
отклонения L, Ψ, K и J. Доля допустимых результатов определяется по полю `status`.
Для этой доли при биномиальной модели рассчитывается 95%-й доверительный интервал
методом Уилсона.

Процентное уменьшение показателя определяется отношением средних:

```text
reduction_percent = 100 * (baseline_mean - candidate_mean) / baseline_mean
```

Положительное значение означает уменьшение. Эта величина отличается от среднего
значения процентов, вычисленных отдельно для каждой задачи.

## Связанные сравнения

Результаты сопоставляются по одинаковым задачам. Односторонний критерий Уилкоксона
проверяет уменьшение Ψ, K и J в варианте `Astar-L-Psi-K` относительно
`Astar-L`, `Astar-L-Psi` и `Astar-L-K`.

Разности с модулем не более 10⁻¹² исключаются. Совпадающим абсолютным разностям
присваиваются средние ранги. При числе ненулевых разностей не более 25
используется точное распределение сумм рангов по сочетаниям знаков; при большем
числе — нормальное приближение с поправками на совпадающие ранги и непрерывность.

Применяется поправка Холма — Бонферрони: отдельно для девяти сравнений общей
выборки и 36 сравнений общей выборки и отдельных сред. В файлах приведены
исходные значения `p_one_sided` и скорректированные `p_holm`.

## Доверительные интервалы процентных изменений

Используется бутстреп-метод с 10 000 повторений и начальным значением генератора
20261014. В каждом повторении внутри каждой среды с возвращением выбирается
столько задач, сколько имеется в исходной группе. Результаты двух сравниваемых
вариантов для выбранной задачи учитываются совместно.

По каждой повторной выборке вычисляется отношение средних. Границами 95%-го
интервала служат квантили 0,025 и 0,975 полученных значений. Оценка относится
к выбору задач в заданных средах, а не к выбору новых карт.
