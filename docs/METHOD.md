# Постановка задачи и алгоритм

## Конфигурации и допустимые переходы

Конфигурация агента включает положение `p = (x, y, z)` и угол курса `psi`.
Координаты положения дискретизируются с шагом 5 м; курс принимает 16 значений
с шагом π/8. Вершина графа задаётся тремя пространственными индексами и индексом
курса. Начальная и целевая конфигурации выбираются из множества вершин графа.

Для перехода между двумя конфигурациями определяются евклидова длина `l`
и модуль кратчайшей разности углов `delta_psi`. Переход допускается при выполнении
следующих условий:

1. Обе конфигурации принадлежат свободной области.
2. Соединяющий положения отрезок не пересекает увеличенные области препятствий.
3. Выполняется `delta_psi / l <= 1 / r_psi`.
4. Азимут горизонтальной проекции перехода отличается от среднего курса
   не более чем на `0.51 * pi / 8`.

Переход без изменения положения исключается. Для чисто вертикального перехода
условие согласования азимута не применяется. Пересечение отрезка с прямоугольным
параллелепипедом проверяется аналитически. Касание границы считается пересечением.

Параметр `r_psi` ограничивает изменение курса относительно длины перехода.
Он не определяет минимальный пространственный радиус поворота. Крен, тангаж,
время движения, скорости и ускорения в модель не входят.

## Показатели и функция стоимости

Для последовательности конфигураций вычисляются:

```text
L = sum(l_k)
Psi = sum(delta_psi_k)
K = sum(delta_psi_k**2 / l_k)
J = alpha * L / L0 + beta * Psi / pi + gamma * K / K0
K0 = L0 / r_psi**2
```

При `L0 = 5 м` и `r_psi = 15 м` все составляющие J безразмерны. Для поиска
используются веса соответствующего варианта. При сопоставлении результатов
применяются одинаковые веса `(0.5, 0.3, 0.2)`.

K — показатель изменения курса, заданный приведённой суммой. Он не является
интегралом квадрата пространственной кривизны. Значение `search_cost` отражает
стоимость, применённую при поиске, и может отличаться от оценочного J.

## Поиск A*

При обработке вершины формируются соседние конфигурации. Изменение каждого
пространственного индекса допускается в пределах двух шагов, индекса курса —
двух угловых шагов с учётом периодичности.

Эвристическая оценка равна `alpha * distance(p, p_goal) / L0`.
Равные приоритеты разрешаются по порядку добавления вершин в очередь.
Поиск завершается при извлечении целевой вершины, исчерпании очереди либо
достижении предела 500 000 обработанных вершин.

## Сглаживание

Сглаживание применяется к пути `Astar-L` и сохраняет начальную и целевую
конфигурации. Сначала для каждой оставляемой конфигурации выбирается наиболее
удалённая последующая конфигурация, допускающая прямой переход по указанным
условиям. Промежуточные конфигурации удаляются.

Для каждого оставшегося перехода строится полиномиальная кривая пятой степени.
Положения на концах заданы исходными конфигурациями. Горизонтальные направления
касательных соответствуют углам курса; длина горизонтальной составляющей
производной равна длине горизонтальной проекции хорды. Вертикальная составляющая
производной равна разности высот. Вторые производные на концах принимаются
нулевыми.

Кривая разбивается на 16 интервалов. Курс во внутренних точках определяется
по азимуту производной. Для чисто вертикального перехода курс интерполируется
вдоль кратчайшего углового интервала. Полученные отрезки проверяются по тем же
условиям допустимости. При нарушении хотя бы одного условия сохраняется прямой
допустимый переход.

Результат представлен последовательностью положений и курсов. Промежуточные
конфигурации могут не принадлежать вершинам исходного графа. Проверка отрезков
не устанавливает отсутствие пересечений непрерывной полиномиальной кривой
с препятствиями или ограничение её пространственной кривизны.
