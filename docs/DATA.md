# Данные эксперимента

## Состав набора

В каждой из трёх сред выбрано по 100 пар начальных и целевых конфигураций.
Во всех вариантах планирования используются одинаковые пары.

| Среда | Расположение препятствий | Число препятствий | Число задач |
|---|---|---:|---:|
| `simple` | Изолированные препятствия | 5 | 100 |
| `complex` | Изолированные препятствия | 18 | 100 |
| `labyrinth` | Протяжённые препятствия | 24 | 100 |

Координаты препятствий и размеры среды приведены в `maps.json`, пары конфигураций —
в `pairs.csv`. Индексы положения и курса выбираются равномерно. Недопустимые
конфигурации, повторные пары и пары с расстоянием между положениями менее 150 м
отбрасываются. Начальное значение генератора случайных чисел — 20260919;
для следующих сред оно увеличивается на 1000 и 2000 соответственно.

Реализация и геометрия сред сформированы по описанию постановки задачи.
Реализация и карты ранних экспериментов не сохранились. Приведённые данные
и команды воспроизводят эксперимент с конфигурациями и средами из этого набора.

## Каталоги результатов

`results/search_300` содержит 1200 сохранённых результатов четырёх вариантов A*.
Файлы используются как входные данные для сглаживания и статистической обработки.
Записи варианта со сглаживанием из исходного запуска не используются.

`results/experiment_300` содержит 1500 результатов: четыре поисковых варианта
и сглаживание 300 путей `Astar-L`. Поисковые пути сохранены; сглаживание
и статистическая обработка выполнены отдельно.

| Файл | Содержание |
|---|---|
| `raw_runs.csv` | Одна строка на задачу и вариант планирования |
| `paths.ndjson.gz` | Положения, курсы и индексы конфигураций пути |
| `pairs.csv` | Начальные и целевые конфигурации |
| `maps.json` | Геометрия сред и препятствий |
| `resolved_config.json` | Параметры расчёта |
| `core_config.json` | Параметры модели для загрузки и проверки |
| `article_summary.csv` | Средние значения, стандартные отклонения и доли допустимых результатов |
| `article_comparisons.csv` | Сравнения по общей выборке |
| `wilcoxon.csv` | Сравнения по общей выборке и по средам |
| `paired_effects_ci.csv` | Процентные изменения средних и доверительные интервалы |
| `path_equivalence.csv` | Совпадение последовательностей положений |
| `postprocess_diagnostics.csv` | Число принятых и отклонённых полиномиальных замен |
| `sampling_sensitivity.csv` | Сравнение разбиения на 16 и 32 интервала |
| `processing_metadata.json` | Параметры обработки, версии среды и контрольные суммы входных файлов |
| `audit_report.json` | Результат проверки сохранённых путей |

## Поля таблицы результатов

| Поле | Значение |
|---|---|
| `map`, `pair_id`, `method` | Среда, номер задачи и вариант планирования |
| `status` | `ok`, `invalid_endpoint`, `no_path` или `expansion_limit` |
| `length_m` | Длина L, м |
| `course_change_rad` | Суммарное изменение курса Ψ, рад |
| `heading_penalty_inv_m` | Показатель K, м⁻¹ |
| `normalized_criterion` | Значение J с одинаковыми оценочными весами |
| `search_cost` | Стоимость, применённая при поиске |
| `expanded`, `generated` | Число обработанных вершин и записей, добавленных в очередь |
| `path_sha256` | SHA-256 последовательности положений |
| `runtime_s` | Время варианта; для обработки сохранённых путей `Astar-L-S` отсутствует |
| `search_runtime_s` | Сохранённое время поиска |
| `postprocess_runtime_s` | Время отдельного расчёта сглаживания |

Значения `NaN` обозначают отсутствие численного результата или измерения.
У сглаженных путей поле `states` равно `null`, поскольку их конфигурации
могут не принадлежать дискретному графу. Курсы хранятся в поле `headings`.
Для путей A* курс определяется индексом конфигурации в `states`.

## Измерение времени

Сохранённые времена четырёх вариантов A* получены в запуске с восемью процессами.
Описание процессора, памяти и операционной системы этого запуска отсутствует.
Сведения, имеющиеся об исходном запуске, приведены в `run_metadata.json`.
Его `wall_runtime_s` относится ко всему исходному запуску, включая вариант
сглаживания, записи которого не включены в `search_300`.

Сглаживание сохранённых путей измерено отдельно. Эти значения не складываются
с сохранённым временем поиска, поскольку сопоставимость вычислительных условий
не подтверждена. При полном расчёте `run_experiment.py` время `Astar-L-S`
включает поиск и сглаживание из одного запуска.

## Воспроизводимость

Результаты обработки можно получить из `search_300` без повторного поиска.
Доверительные интервалы используют фиксированное начальное значение генератора
случайных чисел. Время расчётов зависит от оборудования и нагрузки.

Проверка сохранённых данных включает все 1500 путей. Полный повтор 1200 поисков
для этого набора не выполнялся; контрольный повтор одной задачи среды `simple`
воспроизвёл последовательности положений четырёх вариантов A*.
