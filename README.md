# Многокритериальное планирование пути в трёхмерной среде

Программная реализация поиска пути алгоритмом A* с ограничением изменения курса.
Рассматриваются четыре варианта функции стоимости и сглаживание пути, найденного
по длине. Набор данных содержит 300 пар начальных и целевых конфигураций в трёх
вариантах расположения препятствий.

## Модель и параметры

Конфигурация агента задаётся координатами положения и углом курса:
`q = (x, y, z, psi)`. Препятствия представлены прямоугольными параллелепипедами.
Переход допускается при отсутствии пересечения с увеличенными областями
препятствий и выполнении ограничения `delta_psi / length <= 1 / r_psi`.
Для перехода с горизонтальной составляющей дополнительно проверяется
согласование его азимута со средним углом курса.

| Параметр | Значение |
|---|---|
| Размеры рабочей среды | 250 × 250 × 100 м |
| Шаг по координатам | 5 м |
| Число значений курса | 16 |
| Шаг по курсу | π/8 рад |
| Параметр rψ | 15 м |
| Увеличение областей препятствий | 5 м |
| Минимальное расстояние между положениями начальной и целевой конфигураций | 150 м |
| Изменение пространственных индексов за переход | Не более двух шагов по каждой оси |
| Изменение индекса курса за переход | Не более двух шагов |
| Предельное число обработанных вершин | 500 000 |

Параметры основного эксперимента заданы в `default_config.json`.
Файл `config_26_neighbors.json` задаёт меньшую окрестность поиска и не используется
для таблиц сохранённого эксперимента.

## Варианты планирования

| Идентификатор | Состав функции стоимости | α | β | γ |
|---|---|---:|---:|---:|
| `Astar-L` | Длина | 1,0 | 0 | 0 |
| `Astar-L-S` | Поиск по длине со сглаживанием | 1,0 | 0 | 0 |
| `Astar-L-Psi` | Длина и изменение курса | 0,7 | 0,3 | 0 |
| `Astar-L-K` | Длина и показатель K | 0,7 | 0 | 0,3 |
| `Astar-L-Psi-K` | Длина, изменение курса и показатель K | 0,5 | 0,3 | 0,2 |

Показатель K определяется суммой квадратов изменений курса, отнесённых к длинам
переходов. При сравнении результатов значение J вычисляется с одинаковыми весами
`(0.5, 0.3, 0.2)` для всех вариантов. Определения показателей и алгоритм сглаживания
приведены в [описании метода](docs/METHOD.md).

## Установка

Требуется Python 3.11 или новее. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его командой `source .venv/bin/activate` в Linux/macOS либо
`.venv\Scripts\Activate.ps1` в Windows PowerShell. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Расчёт по сохранённым путям

Команда выполняет сглаживание 300 сохранённых путей `Astar-L`, вычисляет показатели
всех пяти вариантов и проводит статистическое сравнение. Повторный поиск A*
не выполняется.

```bash
python scripts/reprocess_saved_results.py --source results/search_300 --output output/processed_300
python scripts/audit_saved_results.py output/processed_300
```

Результаты основного эксперимента находятся в `results/experiment_300`.
Их сводная таблица приведена в [RESULTS.md](RESULTS.md).
Назначение файлов и условия измерения времени описаны в
[описании данных](docs/DATA.md), статистические процедуры — в
[описании статистической обработки](docs/STATISTICS.md).

## Полный расчёт

```bash
python run_experiment.py --pairs-per-map 100 --workers 8 --output output/full_300
python scripts/analyze_full_run.py output/full_300
python scripts/audit_saved_results.py output/full_300
```

Выполняются поиск и сглаживание для всех 300 задач. Время обоих этапов измеряется
в одном запуске. Параметр `--workers` задаёт число процессов; доступная память
должна позволять выполнять соответствующее число поисков A* одновременно.

Для расчёта одной задачи в среде `simple`:

```bash
python run_experiment.py --pairs-per-map 1 --maps simple --workers 1 --output output/example
```

## Замер времени варианта со сглаживанием

19 октября 2026 года выполнен отдельный запуск `Astar-L-S` на тех же 300 задачах
(по 100 в каждой среде) с восемью рабочими процессами. Среднее суммарное время
поиска A* и сглаживания составило **12,33 ± 12,85 с**; после знака ± указано
выборочное стандартное отклонение по задачам. Все 300 путей прошли проверку
допустимости и совпали с опубликованными результатами по контрольным суммам;
геометрические показатели воспроизведены без изменений.

```bash
python run_experiment.py --config default_config.json --pairs-per-map 100 --maps simple,complex,labyrinth --methods Astar-L-S --workers 8 --output output/timing_astar_l_s_20261019
```

Использована версия кода `b18107c96e6212be699f41962b5661527ca57718`,
Python 3.12.14 и Linux x86_64. Время включает поиск, построение и проверку
сглаживания; вычисление итоговых метрик и запись файлов в него не входят.
Замер выполнен отдельно от архивных запусков остальных четырёх вариантов,
поэтому времена между этими запусками напрямую не сопоставляются.

## Проверка

```bash
python -m unittest discover -s tests -v
python scripts/audit_saved_results.py results/experiment_300
```

Проверяются показатели сохранённых путей, контрольные суммы положений, начальные
и целевые конфигурации, пересечения с препятствиями и допустимость переходов.
Для путей A* дополнительно проверяется принадлежность переходов исходному графу.
