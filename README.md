# Геометрическое планирование пути с ограничением изменения курса

Версия материалов к исправленной статье: **review-2026-10-14**.

Пакет содержит четыре варианта A* и исправленную квинтическую постобработку,
сохраняющую начальные и целевые положения и курсы. Модель задаётся конфигурацией
`q = (x, y, z, psi)`. Это геометрическое планирование с дискретным ограничением
изменения курса; гарантии пространственного радиуса поворота, энергосбережения
или динамической реализуемости не заявляются.

## Какие результаты использовать

**Таблицы исправленной статьи получены из `results/reviewed_300`.**

`results/full_300` — предоставленный исходный архив эксперимента. Четыре
поисковых варианта из него сохранены. Старый вариант `Astar-L-S` не используется
в исправленной статье: он не сохранял заданные граничные курсы и оценивался по
240 успешным задачам. Старые файлы оставлены для проверки происхождения изменений.

Геометрия сред и программная реализация в исходном пакете были реконструированы
по описанию переработанной статьи; ранняя реализация и ранние карты не сохранились.
Предоставленные сохранённые пути согласуются с кодом и численными результатами.
Репозиторий воспроизводит именно представленный здесь эксперимент.

## Обозначения

| В коде | В статье | Состав стоимости поиска |
|---|---|---|
| `Astar-L` | `A*(L)` | длина |
| `Astar-L-S` | `A*(L)+П` | длина, затем допустимая постобработка |
| `Astar-L-Psi` | `A*(L, Psi)` | длина и изменение курса |
| `Astar-L-K` | `A*(L, K)` | длина и показатель K |
| `Astar-L-Psi-K` | `A*(L, Psi, K)` | длина, изменение курса и K |

Во всех оценочных таблицах `J` вычисляется с одними весами `[0.5, 0.3, 0.2]`,
независимо от весов, использованных при поиске. Проценты в исправленной статье
вычисляются как относительное изменение **неокруглённых средних**, а не как
среднее индивидуальных процентов.

Для совместимости с архивными файлами сохранены некоторые старые имена:

* `minimum_turn_radius_m` — это параметр `r_psi` дискретной проверки
  `abs(delta_psi) / transition_length <= 1 / r_psi`, а не физический радиус;
* `curvature_integral_inv_m` — показатель `K = sum(delta_psi**2 / length)`,
  а не полная пространственная кривизна;
* `kinematic_mode = heading_aligned` включает проверку согласования азимута
  с круговым средним курса; название поля не означает учёт полной кинематики.

Крен, тангаж, скорости и ускорения не моделируются. Курс относится к
горизонтальной плоскости; вертикальное перемещение само по себе не меняет курс.

## Основные параметры

Рабочая среда `250 x 250 x 100 м`, пространственный шаг `5 м`, 16 курсов с
шагом `pi/8`, `r_psi = 15 м`, безопасное расстояние `5 м`, `L0 = 5 м`.
Допуск согласования азимута равен `0.51 * pi/8`. Пространственные индексы
соседей меняются не более чем на два шага по каждой оси, курс — не более чем
на два шага циклически. Предел обработки — 500000 вершин.

Полная конфигурация находится в `default_config.json`. Проверка отрезка на
пересечение увеличенных прямоугольных препятствий выполняется аналитически;
параметр `edge_samples` сохранён только для совместимости.

Для каждой из трёх фиксированных сред выбрано по 100 пар конфигураций.
Пространственные индексы и курс выбираются равномерно; недопустимые,
повторные и слишком близкие пары отбрасываются. Расстояние между положениями
должно быть не менее 150 м. Используются сохранённые начальные состояния
генератора случайных чисел.

## Установка и проверка

Требуется Python 3.11 или новее; пакет проверен с Python 3.12.14 и Pillow 12.3.0.

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/audit_saved_results.py
```

Аудит проверяет 1500 возвращённых путей: соответствие CSV, хеши положений,
граничные конфигурации, допустимость и показатели. Для четырёх поисковых
вариантов дополнительно проверяется принадлежность каждого перехода графу.

Контрольный полный запуск всех вариантов для одной задачи:

```bash
python run_experiment.py --pairs-per-map 1 --maps simple --workers 1 --output output/smoke
```

Такой контрольный запуск воспроизвёл сохранённые последовательности положений
всех четырёх вариантов A*. В полном архиве проверена согласованность всех
сохранённых путей и показателей; все 1200 поисков повторно не выполнялись.

## Воспроизведение исправленных таблиц без повторного A*

```bash
python scripts/reprocess_saved_results.py --source results/full_300 --output output/reviewed_300
python scripts/audit_saved_results.py output/reviewed_300
```

Скрипт сохраняет четыре исходных поисковых варианта, заново выполняет
постобработку 300 путей по длине, рассчитывает единые показатели, парные
интервалы эффекта и статистические сравнения. Генерируются:

* `raw_runs.csv` — 1500 результатов;
* `paths.ndjson.gz` — положения, курсы и, для A*, индексы состояний;
* `article_summary.csv` — таблица средних и стандартных отклонений;
* `paired_effects_ci.csv` — относительные изменения средних и 95%-е интервалы;
* `article_comparisons.csv`, `wilcoxon.csv` — связанные сравнения и коррекция Холма;
* `postprocess_diagnostics.csv` — число принятых квинтических замен и контроль границ;
* `sampling_sensitivity.csv` — контроль 16 против 32 интервалов;
* `maps.json`, `pairs.csv`, конфигурации и `review_metadata.json` — точные входы и происхождение.

Перевыбор для bootstrap выполняется по парам внутри каждой из трёх фиксированных
сред: 10000 повторений, seed 20261014. Это оценивает неопределённость выбора
пар на этих средах, а не разнообразие произвольных карт. Нулевые разности
Уилкоксона определяются допуском `1e-12`; равные ранги усредняются. При числе
ненулевых разностей до 25 используется точное распределение по знакам; иначе
нормальное приближение с корректной поправкой на связанные ранги и непрерывность.
Холм применяется отдельно к девяти агрегированным сравнениям и к 36 сравнениям
по средам; исходные p-значения также сохранены.

## Исправленная постобработка

1. Жадно удаляются промежуточные конфигурации, только если прямой переход между
   оставляемыми конфигурациями допустим по препятствиям, изменению курса и азимуту.
2. Между оставшимися конфигурациями строится квинтический Hermite-переход с
   заданными положениями, горизонтальными направлениями касательных и нулевыми
   вторыми производными на концах. Масштабы производных определяются хордой.
3. На 16 интервалах формируются положения и курсы; для непустой горизонтальной
   проекции курс берётся из азимута производной, для вертикали интерполируется.
4. Все возвращаемые дискретные переходы проверяются теми же условиями. Если
   предложение недопустимо, сохраняется допустимый прямой переход.

Граничные конфигурации сохраняются точно. Проверяется возвращаемая ломаная;
отсутствие пересечения непрерывного полинома между точками контроля и его
непрерывная пространственная кривизна не сертифицируются. Постобработка может
выходить за пределы исходного дискретного графа.

## Полный новый эксперимент

```bash
python run_experiment.py --pairs-per-map 100 --workers 8 --output output/new_full_300
python scripts/summarize_article_results.py output/new_full_300
```

Полный запуск рассчитывает все варианты уже с исправленной постобработкой.
В отличие от повторной обработки сохранённых данных, он измеряет поиск и
постобработку в одном окружении. При увеличении числа процессов нужно учитывать
память, расходуемую независимыми экземплярами A*.

Для полученного нового набора bootstrap-анализ выполняется отдельным скриптом
`scripts/analyze_full_run.py`; он не заменяет постобработку и не смешивает время.

## Ограничение архивного времени

В исходном полном запуске сохранены число процессов и времена поиска, но нет
достоверного описания процессора, памяти, ОС и версий зависимостей. Поэтому
архивные времена четырёх A* не следует трактовать как универсальное быстродействие.
Повторная постобработка выполнена в другом окружении: её время записано отдельно,
а `runtime_s` исправленного `Astar-L-S` оставлено `NaN`. В статье для этой ячейки
используется прочерк. Получить сопоставимое общее время можно полным новым запуском
на одном компьютере с сохранением его описания.
